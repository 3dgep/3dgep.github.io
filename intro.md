**3D Game Engine Programming** (3dgep) is an educational resource for teaching new (and old) game developers about game engine programming. The primary focus is graphics programming, covering APIs like OpenGL, DirectX, and Vulkan, as well as other game engine topics such as audio, physics, and general engine architecture.

## What You'll Find Here

- Step-by-step **graphics programming tutorials** using modern APIs
- Deep dives into **engine architecture and design patterns**
- Coverage of **audio, physics**, and other engine subsystems
- Content aimed at both beginners and experienced developers
